## English

This repository supports the deployment of **science‑related applications** on **OKD, OpenShift, and Kubernetes**.

Where possible, this repository:
- Links to **upstream application repositories** to which we have contributed OKD/OpenShift deployment code.
- Hosts deployment code **during migration**, or **when upstream integration is not possible**.

➡ **Technical and operational instructions are provided within each individual application’s code or subdirectory.**

Contributors **must review the file `UPSTREAM-AMONT`**, which includes guidance and the **recommended statement to be added to upstream licence files**, where permitted by the upstream projec

## 🇫🇷 Français

Ce dépôt soutient le déploiement **d’applications scientifiques** sur **OKD, OpenShift et Kubernetes**.

Lorsque possible, ce dépôt :
- Référence les **dépôts sources des applications** auxquels nous avons contribué du code de déploiement OKD/OpenShift.
- Héberge le code **pendant une migration**, ou **lorsque l’intégration dans le dépôt source n’est pas possible**.

➡ **Les instructions techniques et opérationnelles se trouvent avec le code de chaque application.**

Les contributeurs **doivent consulter le fichier `UPSTREAM-AMONT`**, qui contient des orientations ainsi que **l’énoncé recommandé à ajouter aux fichiers de licence en amont**, lorsque cela est permis par le projet en amont.
